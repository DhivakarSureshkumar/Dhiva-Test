# ZeTa Generated Tests

Tests generated by ZeTa AI Quality Intelligence.

## Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Install browser binaries
npx playwright install --with-deps

# 3. Set your application URL in .env
#    Edit .env and replace https://your-app.com with your actual app URL

# 4. Run all tests
npm test
```

## Other Commands

| Command | Description |
|---|---|
| `npm run test:headed` | Run in headed browser (visible) |
| `npm run test:ui` | Open Playwright UI mode |
| `npm run report` | Open HTML test report |

## Project Structure

```
pages/           Page Object Models
  base.page.ts   Base class (locator helpers, navigation)
  *.page.ts      Generated page objects per screen
tests/           Generated spec files
  fixtures/      Shared test fixtures
playwright.config.ts
.env             App URL + credentials (git-ignored)
```
